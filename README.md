# TechSibling_AI — From College  to Career

## 📌 About the Project

RoleBridge AI is a career guidance and skill development platform designed to help college students connect their academic learning with real-world industry requirements.

Students often learn subjects throughout their degree without understanding how those subjects are used in software companies or other industries. They may also struggle to identify the skills required for their desired job roles and when to start learning them.

RoleBridge AI aims to solve this problem by providing branch-specific career guidance, industry skill recommendations, semester-wise learning roadmaps, and practical explanations of college subjects.

## 🎯 Objectives

- Help students discover career opportunities related to their engineering branch and interests.
- Identify the technical skills required for different job roles.
- Provide a structured learning roadmap covering all eight semesters of a four-year degree.
- Explain how college subjects are applied in real-world industries.
- Help students track their learning progress.
- Prepare students for internships, projects, and future job opportunities.

## ✨ Features

### 1. Student Profile
Students can enter their name, college, engineering branch, current year, semester, and preferred career.

### 2. Career Role Explorer
Explore different career paths, such as:
- Software Developer
- AI/ML Engineer
- Data Analyst
- Cloud Engineer
- Cybersecurity Analyst
- Electronics / Hardware Engineer
- Mechanical Design Engineer
- Civil Engineer

### 3. Industry Skills Guide
Each career role provides a list of relevant technical skills, practical applications, and suggested projects.

### 4. Eight-Semester Learning Roadmap
The platform organizes learning targets across eight semesters, from programming fundamentals to advanced projects and placement preparation.

### 5. Learning Progress Tracker
Students can mark learning targets as completed and view their overall progress. Progress is saved locally in the browser.

### 6. Syllabus-to-Industry Translator
Students can enter a subject name or paste syllabus topics to view a prepared explanation of the subject's industry applications and additional skills to practice.

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling and responsive layout
- **JavaScript** — Interactive features and career roadmap logic
- **Browser Local Storage** — Saving student profile and learning progress

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure the following files are present:
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
4. Install the Live Server extension in VS Code if it is not already installed.
5. Open `index.html`.
6. Right-click the file and select **Open with Live Server**.
7. Explore the career roles, generate a learning roadmap, and test the syllabus analyzer.
